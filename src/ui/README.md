# `src/ui` — React user interface

## Structure

| Folder                | Purpose                                                                                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/`                | App shell, router, providers, query client, route error screen, the way back from a match to the history, the app version                                       |
| `features/<feature>/` | Screens and components of one feature (account, dashboard, matches, match-detail, review, settings, update) and their hooks                                     |
| `components/`         | Shared presentational components (button, panel, status line, result badge, stat tile, segmented control, tabs…), the shared button styles and the focus helper |
| `format/`             | Display formatters shared by several features (durations, dates in the local time zone)                                                                         |
| `i18n/`               | i18next setup and the `en`/`fr` catalogues                                                                                                                      |
| `theme/`              | `theme.css` only (design tokens); Inter comes from `@fontsource-variable/inter`                                                                                 |

## Shared components

Every screen draws its blocks with these, so that a button, a box or a status line looks and behaves the same everywhere. A component owns its colours, border and padding: the `className` of a caller is for layout and margins only.

| File                              | Role                                                                                                                                                                                                                                                                |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `components/Button.tsx`           | The button, in one of three looks (`primary`, `subtle`, `destructive`: the classes of `button-styles.ts`), with an optional icon that turns while the action runs. It is `type="button"` unless told otherwise                                                      |
| `components/Panel.tsx`            | The bordered box on the surface colour, with three paddings; `PANEL_CLASSES` is exported for the few boxes that cannot be the component (a native `<dialog>`, a list that scrolls)                                                                                  |
| `components/StatusLine.tsx`       | The one line a screen shows while its data loads (a polite status), when loading failed (the `error` kind, an alert explained by the kind of the error and never shown raw), or when the screen words a failure itself (the `alert` kind, which takes a fixed text) |
| `components/ResultBadge.tsx`      | The square of a win or a loss, in two sizes: a filled square against an outlined one, so that the result never rests on its colour alone; a screen reader gets the word, not the letter                                                                             |
| `components/StatTile.tsx`         | A tile with one figure and its label, for a `<dl>` of numbers                                                                                                                                                                                                       |
| `components/SegmentedControl.tsx` | A row of choices of which one is picked, drawn over a native radio group, so that the arrow keys and the screen readers need no code of their own; the filters of the history and the language of the settings use it                                               |
| `components/Tabs.tsx`             | The tabs of the WAI-ARIA pattern. When the selection changes and the focus went away with the old panel (a link in it switched the tab), the selected tab takes the focus; a focus anywhere else, and a page that opens at a tab, are left alone                    |
| `format/date.ts`                  | The dates, in the language of the interface and the local time zone: short and medium dates and times, the local day a time falls on, and whether it is today or yesterday. A match starts in seconds, the times the app stamps are in milliseconds                 |

## The dashboard

The dashboard (`/`) sums up the player's latest matches. Without a linked account it invites the player to link one. Otherwise it shows, from top to bottom: the synchronisation banner, the results of the latest 10 Paige matches in normal modes as a row of W/L badges (each a link to its match), two figures over those matches (the wins out of the matches, and the average kills, deaths and assists), the first weaknesses and strengths of the review, and the links to the review and to the history. The matches and their figures come from `MatchesService.listLatest`; the points come from the review. Both are read from the local database, and neither waits for the other.

| File                                     | Role                                                                                                                                                                                                                                                  |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/dashboard/DashboardPage.tsx`   | The screen: the states without an account, the banner, the two figures in `StatTile`s and the links                                                                                                                                                   |
| `features/dashboard/LatestResults.tsx`   | The row of result badges, a list so that a screen reader says how many matches there are; the name of each link gives the result, then the day and time, since a row of identical letters would say nothing                                           |
| `features/dashboard/DashboardPoints.tsx` | The first three weaknesses and the first three strengths of the review, side by side on a wide window and stacked on a narrow one, each a link to the tab of the review that lists it; one line says when they are being computed or when none recurs |

## The match history

The history page (`/matches`) lists the whole history of the linked account, every mode included, newest first and grouped by local day ("Today", "Yesterday", then the date). The filters are in the address (`?hero=all|<id>&result=all|win|loss`, Paige and every result unless it says otherwise) and a pick replaces the entry of the browser history instead of adding one. When the account has no match the page says so and shows no filter; when none fits the filters it says that under them. The list comes from `MatchesService.listHistory`, through `useHistory`.

| File                                    | Role                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/matches/MatchesPage.tsx`      | The screen: the banner, the filters read from and written to the address, and the states of the list (loading, error, no account, no match, none fits the filters)                                                                                                                                                                                                                             |
| `features/matches/HistoryFilters.tsx`   | The result filter (all, wins, losses) and the hero filter (Paige, all heroes), two `SegmentedControl`s                                                                                                                                                                                                                                                                                         |
| `features/matches/HistoryList.tsx`      | The list, a native table with a day row before the first match of each day. A match row shows the time, the type, the hero, the result, the K/D/A, the duration and where the archive of the match stands (waiting, ready, unavailable, invalid or removed to free space). The time links to the match, and the whole row is clickable for the mouse                                           |
| `features/matches/use-windowed-rows.ts` | `useWindowedRows`: renders only the rows near the visible part of `<main>` (every row has the same fixed height), with two spacer rows standing for the others, so that a history of thousands of matches scrolls like the full list                                                                                                                                                           |
| `features/matches/SyncBanner.tsx`       | The banner of the synchronisation (when it ran, how far the archive is, a button to synchronise now); the settings page shows it `embedded`, without its panel                                                                                                                                                                                                                                 |
| `features/matches/use-matches.ts`       | The TanStack Query hooks of the history, the dashboard and the header of the match page: `useHistory`, `useMatchSummary`, `useLatestMatches`, the hero names and assets, and the state of the synchronisation                                                                                                                                                                                  |
| `app/history-return.ts`                 | The way back from a match: the list marks the entry of a match it opens, and the match page, finding the mark, goes one step back in the browser history, so that the list returns with its filters in the address and its scroll. A match opened from anywhere else leads to a new visit of the list. The router saves and restores the scroll of `<main>`, the element every page scrolls in |

## The settings

The settings page (`/settings`) is one titled panel per group (all but the account through `SettingsSection`), in this order:

| Section     | File                                       | Content                                                                                                                                                                                                                                                                                                                    |
| ----------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Account     | `features/settings/AccountSection.tsx`     | The linked Steam account, switching to another one and unlinking, which asks first in a dialog that says what goes                                                                                                                                                                                                         |
| Sync        | `features/matches/SyncBanner.tsx`          | The synchronisation banner, `embedded`                                                                                                                                                                                                                                                                                     |
| Storage     | `features/settings/StorageSection.tsx`     | What the archives take against the limit (100, 250, 500, 1000, 2000 or 5000 MB; 500 by default), a select to change the limit, about how many matches it holds, and that the archives of the last 90 days and the 40 newest stay; a limit that would remove archives asks first in a dialog (`StorageCapConfirmation.tsx`) |
| Language    | `features/settings/LanguageSwitcher.tsx`   | The language of the interface, a `SegmentedControl`                                                                                                                                                                                                                                                                        |
| Diagnostics | `features/settings/DiagnosticsSection.tsx` | The detailed log switch (it lets the debug lines reach the log file) and the button that opens the folder of the log files                                                                                                                                                                                                 |
| About       | `features/settings/AboutSection.tsx`       | The version of the app with a button that checks for a newer one (a found version opens the update dialog), its licence and where the licences of the included software are listed, where the match data comes from, the notice that Valve is not involved, and what the app does with the data of the player              |

The hooks of `features/settings/use-settings.ts` read and save the settings, read the storage limit, preview what a lower one would evict (`usePreviewStorageEviction`) and change it, switch the detailed log and open the log folder; the saves of the settings run one after another.

## The review

The review page (`/review`, opened from the sidebar) sums up the player's last 20 analysed matches, compared with the players of the tier above their rank and with the 20 matches before. Its five tabs (`?tab=summary|stats|deaths|damage|players`, the summary by default) are kept in the address, and opening another replaces the entry of the history instead of adding one. The review comes from `ReviewService`, through the hooks of `use-review.ts`.

## The match page

The match page (`/matches/$matchId`) has four tabs, kept in the address (`?tab=analysis|timeline|damage|players`, the analysis by default; `MATCH_TABS` in `app/router.ts`). The timeline tab is named "Chronologie" in French.

| File                                               | Role                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/match-detail/TimelineTab.tsx`            | The timeline tab: the chart, then the list of the deaths, which share the death picked (a row picks its death and the chart draws its marker larger, and the pointer over a marker picks its row). A sentence stands in for both when the archive cannot be read; nothing is shown for a match that is not archived, as the analysis above the tabs says why     |
| `features/match-detail/TimelineChart.tsx`          | The chart, drawn by hand in SVG: the souls of the player over the match against the mean of their lane opponents, on the bands of the phases, with a row of markers under the lines for their deaths, kills and purchases. An avoidable death is a cross inside a ring, so that its colour never tells it alone; a legend names every line and marker            |
| `features/match-detail/timeline-chart-geometry.ts` | Where the chart draws each thing: its frame, the rows of the markers, and the scales from a time and an amount of souls to a place in the frame                                                                                                                                                                                                                  |
| `features/match-detail/DeathList.tsx`              | The deaths of the player: when each came, who killed them and how fast, how many enemies and allies were near, and the verdict. What is not known is said instead of shown as a zero: the deaths when their details are incomplete, the players near and the verdicts when the positions are not in the archive (with the download to come, when one is planned) |
| `features/match-detail/use-match-timeline.ts`      | `useTimelineTab`, the TanStack Query hook of the tab, through `MatchTimelineService`. Its key sits under `BREAKDOWN_QUERY_KEY_OF` with the damage and players tabs, so that whatever refreshes the match details reads it again                                                                                                                                  |

## Rules

- May import `services/` (through hooks and `useServices()`), types and pure helpers from `core/`, and other `ui/` modules — never a port, never an adapter, never `@tauri-apps/*` (enforced by ESLint).
- Components are PascalCase, one per file; hooks are `use-<name>.ts`.
- No hard-coded user-facing text: use `t('…')` with typed keys; add every key to **both** catalogues.
- Colours and fonts come from the tokens of `theme/theme.css` (Tailwind utilities such as `bg-surface`, `text-fg-muted`); never hard-code a colour. Spacing uses Tailwind's default scale.
- Buttons, boxes, status lines and dates come from the shared components and formatters above, not from a copy of their class lists or of an `Intl` call: a copy drifts.
- Accessibility: semantic elements, labels on controls, visible focus, win/loss never conveyed by colour alone.
- Data comes from TanStack Query hooks wrapping services; components never call a service directly in render.
