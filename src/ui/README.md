# `src/ui` — React user interface

## Structure

| Folder                | Purpose                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `app/`                | App shell, router, providers, query client, route error screen                                                      |
| `features/<feature>/` | Screens and components of one feature (account, dashboard, matches, match-detail, review, settings) and their hooks |
| `components/`         | Shared presentational components, the shared button styles and the focus helper                                     |
| `format/`             | Display formatters shared by several features (durations)                                                           |
| `i18n/`               | i18next setup and the `en`/`fr` catalogues                                                                          |
| `theme/`              | `theme.css` only (design tokens); Inter comes from `@fontsource-variable/inter`                                     |

## The review

The review page (`/review`, opened from the sidebar) sums up the player's last 20 analysed matches, compared with the players of the tier above their rank and with the 20 matches before. Its five tabs (`?tab=summary|stats|deaths|damage|players`, the summary by default) are kept in the address, and opening another replaces the entry of the history instead of adding one. The review comes from `ReviewService`, through the hooks of `use-review.ts`.

## The match page

The match page (`/matches/$matchId`) has four tabs, kept in the address (`?tab=analysis|timeline|damage|players`, the analysis by default; `MATCH_TABS` in `app/router.ts`). The timeline tab is named "Chronologie" in French.

| File                                               | Role                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/match-detail/TimelineTab.tsx`            | The timeline tab: the chart, then the list of the deaths, which share the death picked (a row picks its death and the chart draws its marker larger, and the pointer over a marker picks its row). A sentence stands in for both when the archive cannot be read; nothing is shown for a match that is not archived, as the analysis above the tabs says why     |
| `features/match-detail/TimelineChart.tsx`          | The chart, drawn by hand in SVG: the souls of the player over the match against the mean of their lane opponents, on the bands of the phases, with a row of markers under the lines for their deaths, kills and purchases. An avoidable death is a cross inside a ring, so that its colour never tells it alone; a legend names every line and marker            |
| `features/match-detail/timeline-chart-geometry.ts` | Where the chart draws each thing: its frame, the rows of the markers, and the scales from a time and an amount of souls to a place in the frame                                                                                                                                                                                                                  |
| `features/match-detail/DeathList.tsx`              | The deaths of the player: when each came, who killed them and how fast, how many enemies and allies were near, and the verdict. What is not known is said instead of shown as a zero: the deaths when their details are incomplete, the players near and the verdicts when the positions are not in the archive (with the download to come, when one is planned) |
| `features/match-detail/use-match-timeline.ts`      | `useTimelineTab`, the TanStack Query hook of the tab, through `MatchTimelineService`. Its key sits under `BREAKDOWN_QUERY_KEY_OF` with the damage and players tabs, so that whatever refreshes the match details reads it again                                                                                                                                  |

## Rules

- May import `services/` (through hooks and `useServices()`), types and pure helpers from `core/`, and other `ui/` modules — never a port, never an adapter, never `@tauri-apps/*` (enforced by ESLint).
- Components are PascalCase, one per file; hooks are `use-<name>.ts`.
- No hard-coded user-facing text: use `t('…')` with typed keys; add every key to **both** catalogues.
- Colours and fonts come from the tokens of `theme/theme.css` (Tailwind utilities such as `bg-surface`, `text-fg-muted`); never hard-code a colour. Spacing uses Tailwind's default scale.
- Accessibility: semantic elements, labels on controls, visible focus, win/loss never conveyed by colour alone.
- Data comes from TanStack Query hooks wrapping services; components never call a service directly in render.
